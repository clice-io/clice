# Objective-C methods

A message completes its selector with a placeholder for each argument, from the piece the cursor is at; in a message to `super` the method being written passes its own arguments on. A method declared in an implementation gets its whole declaration, and after a dot a method taking no argument reads as a property

The list shows a selector's first piece, the rest as its signature. With `delimiters` the arguments are empty tab stops; with `none`, and where an argument is written already, the piece alone.
